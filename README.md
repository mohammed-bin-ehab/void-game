# VOID — ظلّ الفجوة (النسخة الجماعية)

لعبة بقاء جماعية حتى 8 لاعبين من أجهزة مختلفة. الخادم (Node + WebSocket) يشغّل الثقب ويقرّر من يسقط،
وهو نفسه يقدّم صفحة اللعبة، فتحتاج رابطاً واحداً فقط.

## تجربة محلية
```bash
npm install
MIN_PLAYERS=2 npm start      # على ويندوز PowerShell:  $env:MIN_PLAYERS=2; npm start
```
افتح http://localhost:3000 في تبويبين أو أكثر، واكتب نفس اسم الغرفة في كل تبويب.
(الافتراضي 3 لاعبين على الأقل؛ للتجربة وحدك استخدم MIN_PLAYERS=2 وافتح تبويبين.)

## النشر المجاني على Render
1. ارفع هذا المجلد إلى مستودع GitHub جديد (git init / git add . / git commit / git push).
2. في render.com: New + ← Blueprint (أو Web Service) واختر المستودع. الملف render.yaml يضبط كل شيء:
   - Build: `npm install` — Start: `npm start` — Plan: Free.
3. بعد دقيقة تحصل على رابط مثل https://void-game.onrender.com . أرسله لأصدقائك.
4. ملاحظة: الخطة المجانية تنام بعد ~15 دقيقة بلا استخدام، وأول فتح بعدها يحتاج ~30–50 ثانية. افتحوا الرابط قبل اللعب بدقيقة.

## كيف تُلعب
- كل لاعب يكتب اسمه ونفس اسم الغرفة (أو يفتح رابط الدعوة من زر «نسخ رابط الدعوة»).
- كل لاعب يضغط «جاهز». المضيف (أول من دخل) يرى زر «ابدأ اللعبة» عندما يكتمل 3 لاعبين وكلهم جاهزون.
- بعد البدء لا يدخل أحد. آخر ناجٍ يفوز، ثم يعود الجميع للغرفة تلقائياً.
- الحركة: الماوس أو WASD أو العصا على الموبايل. اندفاع: انقر/Shift/Space/زر «اندفاع». دفع لاعب قريب: E أو النقر الأيمن أو زر «دفع».
- مزايا تلقائية تأتي لمن يتحرك كثيراً: سرعة، فانوس أقوى، درع قصير، اندفاع سريع. وبين فترة وأخرى تنطفئ الإضاءة عن الجميع ثانيتين أو ثلاث.

## الملفات
- `server.js` الغرف والاتصال  ·  `sim.js` عقل الثقب وقواعد السقوط والدفع والمزايا  ·  `index.html` اللعبة

## إعدادات
- `MIN_PLAYERS` أقل عدد للبدء (افتراضي 3)، `PORT` يحدده الاستضافة تلقائياً.
- أرقام الصعوبة في أعلى `sim.js` (MODES)، وبقية أرقام الإحساس في `CFG` داخل `index.html`.
